# 能源研究工作台界面验收 · 2026-09-29

本轮在已有工作台上修改界面和测试。八个 hash 地址、Flask/Jinja、原生 JavaScript、Bootstrap、Chart.js、配置产品名和中英文支持均保留。后端 API、结构、采集流程、评分逻辑、环境配置及已有资料改动未修改。主预览使用独立的本地 5001 端口，避免原服务的模板缓存影响验收。

## 审查发现与处理

| 优先级 | 位置／代码依据 | 原问题 | 本轮处理及用户任务 |

| 3 | 首页和四类目录筛选 | 日期、主题、优先级全部铺开，移动首屏控件过多 | 常用条件直接可见，低频条件展开；显示已应用条件、总数／匹配／本页数，清除只影响当前页 |

## 使用规则

- 信息层级服务于“先选资料，再追溯依据”：默认只有必要元信息和两行摘要，标题自然换行，不统一固定行高。
- 14px 基准正文、16px 长文、24px 页标题；保留系统中英文字体栈；数值使用等宽数字。摘要等次要文字与长文正文分开排版。
- 深蓝用于操作与选中状态，中性色组织资料；警告色仅表示覆盖不全或异常。提高次要文字和表单边界对比度；深色图表使用相应的可辨识配色。三档正文颜色对三档页面背景的最小对比度为浅色 4.86:1、深色 5.68:1；表单边界分别为 3.66:1、4.00:1。
- 同一资料组使用分隔线，首页侧栏不重复嵌套卡片，报告在一张阅读区域中按章节组织。阴影只留给证据抽屉等浮层。
- 来源、日期、样本和结论边界都来自现有接口，不依据 URL 日期或标题自行补齐字段，不把综合分改称可信概率或商业价值。

## 浏览器验收

使用真实资料在 1440、1024、768、390px 检查全部八页。每页 `scrollWidth` 均不超过可用宽度（浏览器滚动条占 15px）。没有通过全局隐藏横向溢出来通过检查。

| 路由 | 八页逐一 hash 直达并刷新，激活页面均正确；论文→新闻→后退→前进→刷新恢复正确页面，当前会话筛选保留 |

| 隔离缺失字段／长文 | 缺失日期“未提供”、无评分不显示 0、无 URL 不生成链接；长中文标题与完整英文摘要不造成整页溢出 |

## 保留的内容边界

现有报告正文把“强化学习和博弈论”归入所引光伏综述的方法，而 P01 摘要明确说明未涉及这些方法。本轮未改写生成结论，也未修改评分或生成逻辑；界面保留系统分析标识、样本不足说明和原始摘要回查。这是后端生成内容需要另行校验的问题，不能把本轮界面验收当作研究结论已经核实。

统计接口的类别字段混合主题、文档类型和等级标签。本轮保留原始分类值，并明确称作“标签出现次数”；没有将其包装为战略重要性。已有报告内容和来源链接是否足以支持每项结论，仍需回查原始资料。
