## Git 保存版本

## 论文计数修复

此前模板中的论文导航项未绑定计数标识，因此侧栏不显示篇数。本次新增 `paper-nav-count`，在未选择类别且当前请求有效时，使用论文接口返回的目录总数更新。

- 侧栏显示全部论文目录数量，当前为 76 篇。
- 标题下分别显示目录匹配数量、本页数量、页内筛选数量。
- 实测选择 Microgrid Control and Optimization 后，目录匹配为 24 篇，侧栏仍为 76 篇；搜索无匹配结果时，页内筛选为 0 篇，侧栏仍为 76 篇。
- 分页、类别筛选、请求失败及较早请求的延迟响应不会覆盖已取得的全目录总数。未筛选请求返回空目录时显示 0。
