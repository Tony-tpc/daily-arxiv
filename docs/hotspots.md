# 能源精选与双榜综合分析

本项目参考 AIHOT `ddf1c19ef2302863748dce51e4fdcd60d4415fc0` 的设计变量、精选缓存和独立来源衰减公式，在原有 Python / Flask 架构中实现。上游 MIT 许可见 [AIHOT-LICENSE.txt](third_party/AIHOT-LICENSE.txt)。项目名称保持不变。

## 分析与精选分开

学术热点使用近 180 天通过论文质量、研究领域、撤稿检查且有有效摘要的论文，不要求达到精选分数。行业热点使用近 30 天的国内能源新闻、政策、行业报告，保留企业动态过滤和研究边界。资料原文少于 100 字符时等待补全；模型仍须判断内容是否足够。缺失、未来、超窗发布日期不能用抓取时间替代。

画像提取系统场景、研究问题、目标、方法、验证、结果、局限和独立事件事实。按固定的问题或议题定义召回最多 10 个候选，一次主判断和一次独立复核均达到 0.8 才关联。复核不读取主判断结果。不同方法可属于同一研究问题，共享方法词不能代替问题判断；不同政策、项目、时间仍保留各自事件事实。DOI、arXiv ID、政策文号和原始 URL 保持强身份，主题 ID 跨运行稳定。

每个主题至少两篇不同论文；每个行业议题至少两份不同资料、两个可核实的原始来源机构。未知机构不估算。相同及高度相似正文的转载、同机构多个栏目不能增加来源数，只有标题观察而无独立正文的合并来源也不能增加数量。背景论文不计行业来源。

综合分析输出六部分：学术为研究问题、关注依据、方法比较、实质进展、证据局限、后续研究问题；行业为近期事件、共同变化、驱动因素、能源系统与市场影响、分歧与不确定性、后续观察点。每段包含成员引用及 fact / inference / question 类型，再经独立证据复核。页面先展示分析，原资料与原文放入折叠证据区。两个热点入口均没有单篇资料回退。

## 持久状态与预算

`python main.py` 在去重后执行主题分析和精选流程，共享每轮 50 条新增或变更资料、300 次新增模型调用预算。`python scheduler.py` 保留新闻每八小时、政策每日、论文和报告每周任务，并每小时只读缓存重算榜单。网页请求不执行模型或采集。

SQLite 默认位于 `data/hotspots/state.sqlite3`。`analysis_profiles` 保存内容哈希、提示词版本、画像、主主题和 complete / pending / awaiting_content / blocked 状态；`analysis_topics` 保存固定定义、完整分析和失败原因；`cache` 保存带模型、路由、提示词内容、轮次的响应；`documents` 继续保存独立精选评分；`sources`、`audits`、`snapshots` 保存来源健康、证据链接核验和榜单快照。旧事件表保留历史数据，不作为公开榜单读取来源。

提示词独立位于 `src/hotspots/prompts/analysis_*.md`，内容哈希控制缓存失效。模型异常、预算耗尽留下待处理状态，空采集轮次可续跑。无效 JSON、越界引用不缓存；审核不通过时最多按复核反馈修订一次，下一次复核只读取原文与修订分析；这些调用计入同一预算。仍不通过的分析不发布，相同输入保留审核结果，材料或模型 / 提示词更新后重新审核。完成的分析和榜单分别事务写入；重建失败时仅保留成员和原文版本完全未变的完整旧结果。

精选仍执行领域预筛和两个独立评分，T1 / T1_5 / T2 初始门槛 60 / 65 / 76 尚待能源样本校准。精选分数仅辅助热点排序，与原有相关性分数分别保存。

## 指标和接口

行业：`10 × Σ 0.5^(报道年龄小时 / 24)`，每个独立原始机构只取最新有效报道。学术：去重论文按 15 天半衰期求和，同分依次比较已知机构多样性和精选均分。机构信息来自明确的 OpenAlex 机构元数据。指标仅覆盖本地样本，不代表全领域趋势；目前缺乏完整可比历史，涨跌保持 unknown，不绘制虚假趋势线。日期精度为天的材料不标六小时新事件。小于 1 的活跃度保留有效数字，避免被四舍五入为零。

- `GET /api/hotspots?board=industry|academic`：前十项、窗口、计算时间、指标、覆盖状态、分析类型和 processing 进度。首页显示前五项。空榜返回 200，无效 board 返回 400。
- `GET /api/hotspots/<id>`：综合 analysis、引用、证据、原始摘要 / 正文、事件事实、时间线、月度资料分布和趋势。不存在或准入失效返回 404。
- `GET /api/intelligence?view=selected|all`：保持原筛选、分页和默认行为。`source_counts` 为当前视图数量；`library_source_counts` 为相同筛选条件下的全部已收录数量，不受精选切换影响。`selection_progress` 区分近期待处理、审核完成、排除与待补全文，并返回实际处理时间。首页数量栏使用已收录数量，精选列表单独显示匹配数。

读取只访问既有结果，重新核对成员准入、时间、原文哈希；证据链接未通过网络核验时不提供可点击链接。后台证据核验与语义引用校验分别记录。超过两小时未重算标记 stale。空榜展示有效资料、独立机构、待处理、待补全文、分析失败和失败来源，不填充原资料列表。

## 验证

行业归组先对照 `src/hotspots/industry_issues.py` 的固定问题定义，分别进行两次独立判断；
不通过才召回其他主题，两轮不一致保持独立。两批合计最多十个候选，避免旧的单事件主题
抢先吸收统计或采访。交易规模、制度进展与独立采访可以支持同一市场运行问题，事件身份
仍独立。纯巡视、人事、薪酬披露与整车出口物流不进入行业分析。

可执行 `python -m src.hotspots.refresh_industry` 补采、补全近期正文、更新来源健康、重建分析并处理精选队列。
主题分析与精选共享每轮既有 50 份资料 / 300 次模型调用预算与缓存；超额持久化续跑，结果经证据审核后发布。原始记录、
队列、缓存与运行日志位于 `data/`，不纳入代码提交。

`python -m unittest discover -s test -p "test_*.py"` 与 `node --test test/*.test.cjs` 使用固定时间、模拟网络和模型。额外执行 Python 编译、JavaScript 语法、可用的 Pyright 和 `git diff --check`。响应式验收覆盖 390 / 640 / 960 / 1440 / 1920px、浅深色、展开证据、长标题、局部表格滚动及空榜；截图见 [screenshots/aihot](screenshots/aihot)。测试材料不写入正式状态库。
