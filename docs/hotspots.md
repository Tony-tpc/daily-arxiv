## 运行与状态

`python main.py` 在去重后执行领域预筛、独立双评分、摘要写作与关系判断，发布结果后继续原有研究分析。
`python scheduler.py` 保留现有采集计划，并注册 `hotspots_hourly`；该任务只读本地资料、健康状态和模型缓存，每小时重新计算热度，不访问网络或模型。
网页不会触发这些任务。`hotspots.enabled: false` 可停用新任务与公开展示，不删除资料。

状态保存在 `hotspots.state_path` 指定的 SQLite 文件中（默认 `data/hotspots/state.sqlite3`）。documents 保存资料、精选结果与成员归属，groups 保存稳定事件/主题标识，cache 保存每一步及每轮模型结果，sources 保存采集健康，audits 保存离线链接核验，digests 保存引用资料的综述，snapshots 保存近30天按小时生成的榜单。复制该文件前应停止写入任务。
每轮最多处理50条新建/内容变更资料及300次新增模型调用。失败或预算耗尽的资料为 pending，后续采集运行即使没有新记录也会继续处理；完成的评分与写作复用持久缓存。单次原始模型请求异常不自动重复付费调用，等待后续任务重试。标题/原文/日期变更、模型路由或提示词版本变更会使相关结果失效。

预筛只判断领域；评分分开独立进行，两次输入相同且互不包含对方结果。预筛 PASS/UNKNOWN 继续处理，BLOCK 不参与新精选和热点。默认 T1/T1_5/T2 均分门槛为60/65/76，均为待能源样本校准的初值。原有 importance_score 不被覆盖。
无有效摘要/报告正文的资料等待内容补全，不生成虚构摘要。单次写作同时生成 display_title、recommendation_reason、facts 与论文 research_topic。原始标题保留用于身份与证据核验。

候选召回以标题、摘要字符二元组重合与实体交集为依据，最多判断10组。置信度至少0.8；召回相似度低于0.85或置信度低于0.9时必须独立复核，两次关系不一致不关联。行业使用同次发生/直接后续/无关/综述四种关系，论文使用具体问题及场景的 SAME_TOPIC 关系。不同论文不会因共享方法词而直接合并。首次只处理行业48小时、论文30天窗口内资料，不触发历史全库模型处理。

## 指标口径

行业榜：近48小时至少两个不同 owner_id；每个机构只取最新原始报道时间，热度为 `10 × Σ 0.5^(年龄小时/24)`。相似标题合并后，provenance.metadata.observations 仍保留每份来源的原始时间、网址、来源和机构。多栏目同机构只算一次，抓取时间不代替发布时间。
六小时趋势排除后来新增或采集不完整的来源；首次启用时需要积累可比来源历史。来源超过三个采集间隔（最少90分钟）未成功或存在错误时，相关趋势标为 unknown。RSS/网页304计入成功检查。日期精度为天的资料不能标为六小时新事件；没有日期、未来日期不入榜。

学术榜：近30天不同 DOI/arXiv/规范资料ID去重，至少两篇；15天半衰期，先按衰减论文数量，再按有证据的机构数、精选均分排序。学术数据库数量不等于独立论文或机构数。机构多样性来自明确的 openalex_institutions，缺失不推断。覆盖说明明确局限于本地准入论文；没有可比完整历史时不展示增长曲线。

只有经过核验的原文链接可在热点证据中点击。暂无事件综述时显示“代表资料摘要”，不会将单篇摘要标为多来源综述。缺少两个来源/两篇论文时榜单为空，但单篇仍可入精选。

## 接口

- `GET /api/hotspots?board=industry|academic`：entries、computed_at、window_hours、metric、coverage、stale、reason、empty_reason。无数据返回200及空数组；无效board返回400。
- `GET /api/hotspots/<id>`：事件/主题、证据、时间线、series及覆盖状态；过期或准入变化返回404。
- `GET /api/intelligence?view=selected|all`：沿用类型、关键词、分页参数；省略view沿用原语义。精选按原始发布日期倒序分组展示。

公开读取不会创建数据库；超过两小时未重算会标记stale。当前准入导致某成员不可公开时，整个旧派生条目先隐藏，等待重算，以免公开陈旧计数或综述。原有资料库保持可用。

## 校准与验收

自动测试使用固定日期和本地模型替身，不需要任何API密钥：`python -m unittest test.test_hotspots`。
上线前应人工标注能源领域精选与事件难例，分别检查精选查准率/召回率、同事件与直接进展误合并率；初始门槛不代表经过领域评测的准确率。
正式验证运行全部 unittest、Node前端行为测试、静态检查与 `git diff --check`。真实数据不足时保留空榜。截图测试样例只能存在临时测试服务，不能写入正式热点状态库。
