# Notion 风格界面验收 · 2026-09-30

按用户提供的 STYLEKIT Notion 提示词调整现有 Flask/Jinja 前端。发生示例冲突时，以提示词的禁止项为准：透明按钮、稳定边框、无位移或缩放、无渐变和重阴影。使用现有原生 CSS 实现对应样式，不新增样式框架。

## 界面改动

- 米色侧栏和资料块（`#f7f6f3`）、白色阅读区、深灰正文（`#37352f`）、细边框（`#e5e7eb`）。标题、正文和元信息通过字号、留白与对比度区分。
- 顶栏显示随页面变化的面包屑；侧栏与操作控件使用本地线性 SVG 图标，移除 Font Awesome 字体 CDN。所有页面标题上方均不放置图标或 emoji。
- 资料块悬停显示装饰性 `⋮⋮` 手柄，内部控件获得键盘焦点时也可见。手柄不提供拖动排序，不进入 Tab 顺序。
- 按钮透明底色，悬停仅提供浅色背景反馈；资料块由 `#f7f6f3` 变为 `#efedea`，按下使用 `#e3e1db`。颜色和透明度过渡均为 150ms。抽屉直接出现，不使用位移；减少动态效果偏好下取消过渡。
- 报告采用连续阅读区，正文最大行宽 72ch；目录与正文分列，手机端目录折叠。保留中性深色主题。

## 浏览器验证

本地预览使用 `http://127.0.0.1:5001/`。十个导航页面分别在 1440、1024、768、390px 视口下测量，共 40 组，`documentElement.scrollWidth` 均未超过 `clientWidth`。没有通过全局隐藏横向溢出实现该结果。
